# พินคงที่ ESP32-S3 สำหรับ Lab02–Lab09

ใช้กับ **ESP32-S3 ของผู้สอน** และยึด OLED, Relay, DHT11 จาก [config.h ของ Lab07](../labs/lab07-smart-home-project/code/lab07_smart_home/config.h) โดยไม่แก้ Lab07 อุปกรณ์ตัวเดิมใช้ GPIO เดิมทุกบท เมื่อเปลี่ยนการทดลองให้ Upload sketch ของบทนั้น ไม่ต้องสลับพินหรือแก้ค่าพินเอง โค้ด Lab02–06 เลือกชุดพินตาม target ที่ compile

เลข GPIO คือเลขสกรีน เช่น `5`/`IO5` ไม่ใช่ขาลำดับที่ 5 บน header ใช้ [ผัง Header ของ Espressif](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.1.html#header-block) เป็นข้อมูลอ้างอิงและอ่านสกรีนบอร์ดจริง ไม่เทียบตำแหน่งข้ามรุ่น

[Lab08 ตรวจเช็กอุปกรณ์ก่อนใช้งาน](../labs/lab08-hardware-check/README.md) ใช้พินชุดเดียวกันนี้ทุกโมดูล มีภาพต่อสายและโค้ดทดสอบก่อนนำไปทำแล็บอื่น

[Lab09 S3 HomeGuard](../labs/lab09-secure-homeguard/README.md) คง OLED SDA8/SCL9, DHT DATA4, Relay IN1=16/IN2=17 และปุ่ม OUT18 พร้อมVCC/GNDตามตาราง ใช้OLED **SH1106/SH1106G** ตามรุ่นผู้สอน ไม่ต้องย้ายสายจากLab07 ปุ่มใช้เปิดphysicalpairingตามขั้นพัฒนา ส่วนstarterpreflightแสดงรหัสDEMOและคงRelayOFF ยังไม่เปิดBLE/SoftAP

## ตารางต่อสายครบทุกโมดูล

| อุปกรณ์ | จาก ESP32-S3/แหล่งจ่าย | ไปพินอุปกรณ์ | ใช้ในแล็บ |
|---|---|---|---|
| LED ภายนอกตัวหลัก | GPIO5 → R 220Ω | LED anode A (+) | 02, 03, 06 |
| LED ภายนอกตัวหลัก | GND | LED cathode K (−) | 02, 03, 06 |
| LED ตัวที่สองสำหรับ pattern | GPIO2 → R 220Ω | LED anode A (+) | 03.5 |
| LED ตัวที่สองสำหรับ pattern | GND | LED cathode K (−) | 03.5 |
| โมดูลปุ่มกด | 3V3 | VCC | 03, 04 |
| โมดูลปุ่มกด | GND | GND | 03, 04 |
| โมดูลปุ่มกด | GPIO18 | OUT | 03, 04 |
| ไฟสามสี 8 mm | 3V3 | VCC | 04 |
| ไฟสามสี | GPIO10 | RD — แดง | 04 |
| ไฟสามสี | GPIO11 | YL — เหลือง | 04 |
| ไฟสามสี | GPIO12 | GY — เขียว | 04 |
| OLED I2C ประมาณ 1 นิ้ว | 3V3 | VCC | 04, เตรียม06, 07 |
| OLED | GND | GND | 04, เตรียม06, 07 |
| OLED | GPIO8 | SDA | 04, เตรียม06, 07 |
| OLED | GPIO9 | SCL | 04, เตรียม06, 07 |
| Relay 2CH | แหล่งจ่ายโมดูล 5V | VCC ตามคู่มือโมดูล | 05, 07 |
| Relay | GND ร่วมกับขั้วลบแหล่งจ่าย | GND | 05, 07 |
| Relay | GPIO16 | IN1 | 05, 07 |
| Relay | GPIO17 | IN2 | 05, 07 |
| HC-SR04 Ultrasonic | แหล่งจ่ายโมดูล 5V | VCC | 05 |
| HC-SR04 | GND ร่วม | GND | 05 |
| HC-SR04 | GPIO6 | TRIG | 05 |
| HC-SR04 ECHO | ECHO → R1 1kΩ → จุด J | จุด J → GPIO7 และจุด J → R2 2kΩ → GND | 05 |
| DHT11 โมดูล | 3V3 | VCC / + | เตรียม06, 07 |
| DHT11 โมดูล | GND | GND / − | เตรียม06, 07 |
| DHT11 โมดูล | GPIO4 | DATA / S / OUT | เตรียม06, 07 |

GPIO2 ในบทนี้ใช้ LED ภายนอกอีกตัว ไม่ใช่ LED onboard ของ S3 ส่วนไฟ `RD/YL/GY` เป็นโมดูลคนละชุดกับ LED ตัวหลัก GPIO5 จึงต่อพร้อมกันได้ ช่องไฟทั้งสามใช้ขั้วบวกร่วมและตั้งค่าเริ่มต้น LOW=เปิด/HIGH=ดับ ต้องเลือกโมดูล 3.3V ที่มี R จำกัดกระแสและกระแสเหมาะกับ GPIO

ปุ่มโมดูลมี R bias ในตัว ใช้ `INPUT` และต่อ **GND/VCC/OUT ครบสามสาย** อ่าน raw ตอนปล่อย/กดแล้วตั้ง `BUTTON_PRESSED_LEVEL` ให้ตรง โดยใช้ค่าเดียวกันใน Lab03/04 ไม่เพิ่ม R ภายนอกและไม่เปลี่ยนไปใช้ปุ่มคนละตัวระหว่างบท

ECHO ของ HC-SR04 ต้องผ่าน divider ตามตาราง ห้ามเข้าขา GPIO7 ตรง ระดับจุด J จาก ECHO5V เป็นประมาณ `5 × 2/(1+2) = 3.33V` โมดูล Relay ต้องรับลอจิก3.3V และไม่ดึง IN ไป5V ถ้าใช้แหล่ง5Vแยก ให้จ่ายเฉพาะอุปกรณ์และต่อ GND ร่วมตามวงจร ไม่ป้อนไฟกลับบอร์ดที่รับไฟ USB

DHT11 เลือกรุ่นรองรับ 3.3V ถ้าไม่มี pull-up ในตัวให้ต่อ R10kΩ ระหว่าง DATA กับ3V3 ถ้าเป็น sensor เปล่าสี่ขา มองหน้าตะแกรง ขาชี้ลง: `1=VCC, 2=DATA, 3=NC ไม่ต่อ, 4=GND` OLED ใช้ตัวเดิมจาก Lab04 ไป Lab07 ไม่ต่อจอ address เดียวกันซ้ำบนบัส

โหลดผ่านหน้าสัมผัส Relay ใช้คนละชุดกับ LED ที่ GPIO5/2: `แหล่งจ่ายโหลด DC+ → COM1`, `NO1 → R220Ω → LED A(+)`, `LED K(−) → แหล่งจ่ายโหลด DC−`, เว้น NC1; CH2 ทำซ้ำด้วย COM2/NO2 และโหลดอีกชุด ไม่ย้าย LED ตัวหลักจาก GPIO5 ไปเป็นโหลด Relay

## ตั้งค่าและใช้สายเดิมต่อเนื่อง

1. เลือก **ESP32S3 Dev Module** ใน Arduino IDE สำหรับบอร์ด CH343 ที่เคยทดสอบในLab07 ใช้ **USB CDC On Boot = Disabled**, Serial Monitor115200 และ Upload115200 เป็นค่าเริ่มต้น เลือก Flash/PSRAM ให้ตรงบอร์ดจริง ดู [ผลตรวจบอร์ดLab07](../labs/lab07-smart-home-project/app-blueprint/mobile/PHYSICAL_TEST_RESULTS.md)
2. ต่อสายตามตารางนี้ครั้งเดียว แล้วเพิ่มอุปกรณ์ใหม่ในพินที่จัดไว้ ไม่มีสัญญาณสองชนิดใช้ GPIO เดียวกัน ใช้ราง3V3/GNDร่วมได้ โดยตรวจว่ารางBreadboardต่อถึงกันจริง
3. เมื่อเปลี่ยนแล็บ โค้ดอ่าน/สั่งเฉพาะอุปกรณ์ของการทดลองนั้น อุปกรณ์ที่ต่อค้างไม่ได้แปลว่าถูกควบคุมพร้อมกันทั้งหมด ขาที่โปรแกรมไม่ได้กำหนดอาจลอย โดยเฉพาะช่วง Reset/ก่อน setup จึงไม่ใช้ pin map เป็นหลักฐานว่า Relay/ไฟจะดับตลอด หากต้องรับรอง default OFF ต้องตรวจ bias/driver ของฮาร์ดแวร์จริง
4. คง GPIO4,8,9,16,17 และโค้ด/เอกสารLab07เดิมทั้งหมด พินที่เพิ่มในบทก่อนหน้าเว้นจากชุดนี้แล้ว การตรวจรอบปรับพินเป็นการตรวจโค้ด/compile/เอกสาร ยังไม่ใช่ผลทดสอบโมดูลที่ต่อค้างจริง
