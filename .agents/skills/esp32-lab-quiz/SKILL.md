# ESP32 Lab Quiz

## คำถามก่อนเริ่มต้น
- 5–8 ข้อ ใส่ใน `<details><summary><b>คลิกเพื่อดูคำถามก่อนเรียน</b></summary>`
- **ห้ามมีคำตอบหรือคำใบ้** เป็นคำถามล้วน กระตุ้นให้คิด เชื่อมกับประสบการณ์เดิม

## คำถามค้นคว้าหลังเรียน
- 3–5 ข้อ ปลายเปิด แต่ละข้อมี "🔎 คำค้นแนะนำ:" อย่างน้อย 2 คำ (ไทย/อังกฤษ)

## แบบทดสอบหลังเรียน
- 10 ข้อ, 4 ตัวเลือก ก/ข/ค/ง, หัวข้อกำกับว่า `**ข้อ N (ง่าย|ปานกลาง|ยาก)**`
- ข้อ 1–3 ง่าย: นิยาม/ข้อเท็จจริง
- ข้อ 4–7 ปานกลาง: อ่านโค้ด, ทำนายผลลัพธ์, เลือกขาที่ถูกต้อง
- ข้อ 8–10 ยาก: หาจุดผิดในโค้ด, วิเคราะห์อาการ, ออกแบบระบบ
- ตัวเลือกผิดต้องเป็นความเข้าใจผิดที่พบบ่อยจริง ไม่ใช่ตัวเลือกที่ผิดชัดเจน
- กระจายคำตอบ ก/ข/ค/ง ให้ใกล้เคียงกัน และตำแหน่งเดียวกันห้ามติดกันเกิน 3 ข้อ
- ห้ามใส่เฉลยใน README
