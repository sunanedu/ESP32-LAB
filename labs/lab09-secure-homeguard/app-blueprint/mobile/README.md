# แอปอ้างอิง Lab09 — ภาพตัวอย่างและโจทย์สำหรับสร้างเอง

Repository นี้ไม่แจก source แอปสำเร็จของผู้สอน โฟลเดอร์นี้เก็บเอกสาร ภาพ และหลักฐานประกอบการเรียนเท่านั้น นักเรียนสร้าง `mobile/` ในโปรเจกต์ของตนจาก [ชุดสเปก](../README.md)

APK พื้นฐาน Lab07 ด้านล่างเป็นตัวอย่างให้ลอง ไม่ใช่ APK รุ่น Security2 ของ Lab09

[ดาวน์โหลด APK พื้นฐาน 1.0.1](../../../../downloads/README.md) · [กลับบทเรียน](../../README.md) · [นโยบายเผยแพร่](../../../../PUBLISHING.md)

1. อ่าน requirements/design/implementation และภาพเป้าหมายจาก app-blueprint
2. เปิดโปรเจกต์ใหม่ ตั้งชื่อ/package/board/ID ของกลุ่ม แล้วให้ AI ทำทีละ phase
3. สร้าง UI/ฐานข้อมูล/transport และ tests ด้วยตนเองตามข้อกำหนด
4. build/install แอปของตนและตรวจบนอุปกรณ์ตาม test-plan
5. ส่ง source/lockfile/หลักฐานที่ตนทำ ห้ามใช้ APK ตัวอย่างแทนงานสร้างแอป

คำอธิบายและผลตรวจอ้างอิงในเอกสารอื่นอาจกล่าวถึงไฟล์หรือเครื่องมือของผู้สอน ให้ใช้เพื่อเข้าใจหน้าที่และผลที่คาดหวัง ไม่ได้หมายความว่ามี implementation นั้นให้คัดลอกในชุดสาธารณะ
